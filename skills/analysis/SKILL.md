# Stage 5: Analysis

Goal: every RQ gets its figure or table, generated by script from the data in
`paper/experiments/`, ready for the manuscript.

## Figures

One Python script per figure in `paper/figures/`, executed with the
`render_figure` MCP tool. Scripts read from `experiments/*/data.csv`, never
from numbers pasted into the script, so the figure regenerates if the
experiment reruns.

After each render, Read the produced PDF and look at it (legend placement,
label sizes, clipping) before wiring it into the manuscript. Drawn figures
(architecture, state, flow diagrams) are covered by the writing skill's
references/diagrams.md, which also lists each field's figure vocabulary.

Conventions:

- Vector PDF, fonts embedded, sized at final physical size so labels match
  the body text: about 3.3in wide for one column of a two-column venue,
  about 5.5in for single-column ML formats. Do not scale down a large
  figure.
- Error bars or shaded CI bands from the repeated runs, using the variance
  convention fixed in plan.md.
- Colorblind-safe palette, plus marker/linestyle variation so the figure
  survives grayscale printing.
- Normalize where it clarifies (speedup over baseline = 1.0) and use the
  geometric mean for normalized results across benchmarks.

## Tables

- `booktabs` (`\toprule`/`\midrule`/`\bottomrule`), no vertical rules;
  consistent precision, units in the header; best result per column in
  bold.
- Standard tables to prepare: experimental-setup summary (hardware, software
  versions, workloads) and the headline comparison table.

## Takeaways

Update `experiments/results.md`: under each RQ, the final figure/table
reference and a one-sentence finding phrased the way it will appear in the
paper ("X sustains 2.3× the throughput of Y beyond 64 clients"). These
sentences become the visually marked takeaways of the Evaluation section.

Also nominate a headline figure (the single plot that makes the paper's
case) as a candidate for Figure 1.

No gate here: flow directly into writing, but keep STATE.md current.
